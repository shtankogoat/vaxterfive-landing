# Vaxter Five — лендинг швейного производства

Статичный сайт без сборки: откройте `index.html` в браузере.

```
index.html        разметка всех блоков
css/style.css     стили (белая тема, адаптив)
js/swatches.js    данные образцов тканей/фурнитуры
js/main.js        бегущая строка, модалка образцов, форма, анимации
img/              логотип, логотипы клиентов, фото (взяты с vaxterfive.ru)
```

Форма заявки пока демонстрационная — нужно подключить отправку (почта / Telegram-бот / CRM) в `js/main.js`.
