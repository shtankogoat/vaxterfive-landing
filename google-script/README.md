# Подключение формы заявок (Google Apps Script)

1. На Google Диске создайте папку (например «Сайт Vaxter Five — заявки»), зайдите в неё и там: **Создать → Google Таблицы**. Таблица и скрипт окажутся внутри этой папки.
2. В таблице: **Расширения → Apps Script**. Удалите код по умолчанию, вставьте содержимое `Code.gs`, сохраните.
3. В редакторе выберите функцию `testSetup` → **Выполнить** → разрешите доступ (таблица и диск).
4. **Развернуть → Новое развертывание** → тип «Веб-приложение»:
   - Запуск от имени: **Я**
   - У кого есть доступ: **Все**
5. Скопируйте URL вида `https://script.google.com/macros/s/…/exec` и вставьте его в `js/main.js` вместо `PASTE_GOOGLE_SCRIPT_URL_HERE`.

После изменения `Code.gs` делайте **Развернуть → Управление развертываниями → Изменить → Новая версия**, иначе останется старая версия (URL не меняется).

Заявки: лист «Заявки» в таблице; файлы — подпапка «Заявки с сайта — файлы» в той же папке, где лежит таблица.
